# 🛒 Ecommerce Sales Dashboard (Power BI)

This project showcases an **interactive Power BI dashboard** built on ecommerce sales data.  
It provides insights into sales, profit, quantity, categories, and customer behavior.

---

## 📂 Project Files
- **Orders.xlsx** → Contains order-level information  
- **Details.xlsx** → Contains product-level details  
- **Ecommerce_Sales_Dashboard.pbix** → Power BI project file  
- **Ecommerce_Dashboard.png** → Dashboard screenshot

## 🔍 Key Insights
- **Total Profit:** 37K  
- **Average Order Value (AOV):** 121K  
- **Total Sales Amount:** 438K  
- **Total Quantity Sold:** 5615  

### Breakdown:
- **Profit by Sub-Category:** Printers and Bookcases generate the highest profits.  
- **Sales by State:** Maharashtra and Madhya Pradesh lead in total sales amount.  
- **Quantity by Payment Mode:** COD is the most preferred mode (~39%).  
- **Quantity by Category:** Clothing contributes the largest share (46.6%).  
- **Profit Trend by Month:** Highest in January, February, and December.  
- **Top Customers:** Madan Mohan, Shiva, and Vishakha contribute significantly to sales.

## 📌 Purpose
This project demonstrates the use of **Power BI for business intelligence** — analyzing ecommerce data to gain insights into customer behavior, product performance, and sales trends.  
It can be used as a learning resource for students and professionals beginning with Power BI.
